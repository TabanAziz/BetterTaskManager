# Changelog

## 1.1.1

- Removed the duplicate app icon and title below the Windows title bar.
- Added visual theme previews and improved contrast for navigation and resource usage.
- App history shows its first results while Windows continues loading the 30-day totals.
- Open file location follows BetterExplorer when it is configured as the default folder manager and BTM is running without elevation.

## 1.1.0 - 2026-11-24

- Choose System, Light, Dark or one of six BetterExplorer themes in Settings.
- Deep Space, Paper White, Candy Rush, Frost, Eclipse and Cyber Grid bring their colors and title bar motifs across the app.
- Theme changes apply immediately and are remembered when BTM reopens.

## 1.0.0 - 2026-11-22

First release.

- Processes, Performance, App history, Startup apps, Users, Details, Services and Settings pages
- Live graphs for CPU, logical processors, memory, disks, network adapters and GPUs
- Optional Ctrl+Shift+Esc takeover and optional read-only elevated helper
- Per-user setup and portable zip
